# 链接画板

粘贴链接 → 自动抓 favicon 变成图标，拖拽排布，数据只存在浏览器 IndexedDB 里。

- 粘贴：⌘V / Ctrl+V（也支持把链接拖进窗口）
- 打开：单击图标直接在新标签页打开
- 重排：右上角「重排」按钮，或按 R，一键排成整齐网格
- 编辑：右键图标（名字、链接、图标地址、底色），双击也可以
- 删除：选中后按 Delete，或编辑框里点删除
- 搜索：右上角输入框
- 存储：IndexedDB（库名 `link-board`，表 `items`），没有后端、没有同步

## 跑起来

```bash
./run.sh            # http://127.0.0.1:8812
PORT=9000 ./run.sh  # 换端口
```

## 图标分组

Shift+单击多选图标，再点「打组」或按 G，输入组名保存。点击组名可改名，＋/− 可展开或折叠，× 解散分组但保留链接。取消弹窗不保存；Esc 清空选择。搜索也匹配组名。组和成员关系存于同一浏览器 IndexedDB，刷新后保留，旧链接自动兼容。
